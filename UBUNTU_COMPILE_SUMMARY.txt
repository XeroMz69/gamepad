================================================================================
QUICK REFERENCE UNTUK UBUNTU
================================================================================

1. INSTALL PREREQUISITES (first time only)
   $ sudo apt install -y openjdk-17-jdk dotnet-sdk-6.0 gradle

2. SETUP ANDROID SDK (first time only)
   $ mkdir -p ~/Android/Sdk/cmdline-tools && cd ~/Android/Sdk/cmdline-tools
   $ wget https://dl.google.com/android/repository/commandlinetools-linux-10135889_latest.zip
   $ unzip commandlinetools-linux-10135889_latest.zip
   $ cat >> ~/.bashrc << 'EOF'
   export ANDROID_SDK_ROOT=$HOME/Android/Sdk
   export PATH=$PATH:$ANDROID_SDK_ROOT/cmdline-tools/latest/bin
   EOF
   $ source ~/.bashrc

3. BUILD ANDROID APK
   $ cd ~/gamepad/android
   $ chmod +x gradlew
   $ ./gradlew assembleRelease
   Output: app/build/outputs/apk/release/app-release.apk

4. BUILD PC SERVER (untuk Windows)
   $ cd ~/gamepad/pc-server
   $ dotnet publish --configuration Release --runtime win-x64
   Output: bin/Release/net6.0-windows/publish/VirtualGamepadServer.exe

5. TRANSFER KE WINDOWS
   $ scp VirtualGamepadServer.exe user@windows-pc:C:\\Users\\user\\Desktop\\

6. INSTALL APK
   $ adb install app-release.apk

7. RUN DI WINDOWS
   - Run VirtualGamepadServer.exe as Administrator
   - Connect dari Android
   - Play!

TROUBLESHOOTING UMUM
================================================================================

❌ "Permission denied: ./gradlew"
✅ $ chmod +x gradlew

❌ "ANDROID_SDK_ROOT not set"
✅ $ export ANDROID_SDK_ROOT=$HOME/Android/Sdk

❌ "Java not found"
✅ $ sudo apt install -y openjdk-17-jdk

❌ ".NET not found"
✅ $ sudo apt install -y dotnet-sdk-6.0

❌ "gradle: command not found"
✅ $ sudo apt install -y gradle

❌ Build hang/slow
✅ $ export GRADLE_OPTS="-Dorg.gradle.parallel=true"
